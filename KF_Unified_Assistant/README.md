# KF 助手 / KF Assistant

[简体中文安装指南](https://github.com/banard2049-cpu/kf-assistant/blob/main/README.md) · [English installation guide](https://github.com/banard2049-cpu/kf-assistant/blob/main/README.en.md)

## 便携版快速启动

Windows 双击 `start-windows.bat`，macOS 双击 `start-macos.command`，然后打开 `http://127.0.0.1:8789/`。将另备的游戏图片放入 `public/assets/`，注册登录后即可新建战役和骑士。更新前用「导出存档」备份，并保留 `data/` 和 `public/assets/`。

## Portable quick start

Double-click `start-windows.bat` on Windows or `start-macos.command` on macOS, then open `http://127.0.0.1:8789/`. Put your game artwork in `public/assets/`, then register and sign in to create a campaign and add knights. Use **Export Save** (「导出存档」) before updating and keep `data/` and `public/assets/`.
