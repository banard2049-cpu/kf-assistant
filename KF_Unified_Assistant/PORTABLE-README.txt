KF 一体化战役助手 - Windows 免安装版

使用方法：
1. 必须先完整解压 ZIP，不能直接在压缩包窗口中运行。
2. 双击“start-windows.bat”。
3. 保持打开的命令行窗口不要关闭；关闭窗口即停止服务。
4. 浏览器会打开 http://127.0.0.1:8789 。

本版本自带 PHP，不需要另外安装 PHP。
首次运行会在当前目录创建 .env、data、backups 和 logs。
请保留这些目录；更新程序前建议备份 data 和 backups。

如果 Windows 防火墙询问是否允许访问：
- 只在本机使用时可以取消。
- 需要让同一局域网内的其他设备访问时，仅允许“专用网络”。

故障排查：
- 端口 8789 被占用时，请先关闭另一份 KF 助手或其他占用该端口的程序。
- 可双击 check-windows.bat 检查内置 PHP 与 SQLite 扩展。
